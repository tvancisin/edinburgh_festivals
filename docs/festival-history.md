# Festival history layout

The foundation history keeps all eleven timelines, names, and data legends on
screen. Its drawing region starts 16 pixels below the measured EFI logo.
Rows use up to 68 pixels of separation, capped by the available region's height.
Text, bars, markers, arrows, and line widths scale together when the measured
width or height is smaller. The drawing uses the component's current dimensions;
it does not add scrolling or hide timelines on smaller screens.

This changes presentation only. Foundation years, festival order, event-data
coverage, and ticketing-data availability are unchanged.
